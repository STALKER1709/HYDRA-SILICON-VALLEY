# Hydra Silicon Valley — Website

Institutional bilingual (French/English) website for Hydra Silicon Valley.

## Stack
- Static HTML, CSS and JavaScript (no build step or runtime dependencies)
- Responsive, mobile-first layout
- Accessible navigation and reduced-motion support
- Vercel static hosting

## Local preview
Open `index.html` in a browser or run a local static server:

```bash
npx serve .
```

## Deployment
Connect this repository to Vercel with the project root set to the repository root. No environment variables or build command are required.
